Integrating TelemetryReporter in Your Applications

Connect any client application (e.g. Prism EDU, POS Pro, ClinicCore) to this SpectraOps Central Hub with zero external dependencies.

1

Include the Telemetry Reporter SDK

Copy client-sdk/TelemetryReporter.php into your project's service layer:

require_once __DIR__ . '/services/TelemetryReporter.php';
use App\Services\TelemetryReporter;
2

Initialize & Register Global Exception Handlers

Register during your application bootstrap to catch unhandled errors:

$reporter = TelemetryReporter::init(
    'http://your-spectraops-hub.com', 
    'flt_your_secret_token_here', 
    '2.5.0' // Current software version
);

// Catches all uncaught exceptions & fatal shutdown errors
TelemetryReporter::registerGlobalHandlers($reporter);
3

Queue Periodic Heartbeats & Metrics

Send non-blocking background telemetry with system health:

$reporter->queueHeartbeat([
    'active_users_24h' => 1280,
    'db_latency_ms'   => $reporter->measureDbLatency($pdo),
    'storage_free_gb' => 310.5,
]);
